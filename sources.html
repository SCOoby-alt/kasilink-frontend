Security, privacy and AI use

Demo data

Plumber names, phone numbers and emails on this site are demonstration data. Please do not enter real passwords or ID numbers. Contact messages are only readable by an administrator.

AI assistant

The chat assistant is rule-based: it answers only from KasiLink SA's own service, price and plumber data and does not call an external AI service.

AI tools used to build this project

The group used an AI assistant to help fix and improve the Java and website code. The group reviewed the changes and can explain them.
